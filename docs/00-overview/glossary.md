# Glossary

- **User Account**: email/password login record and account status. It does not own Agent data directly.
- **Human Principal**: authorization and ownership root for a person. API responses commonly call it `User`.
- **Personal Agent**: persistent configurable product object owned by one Human Principal; not a request, process, Conversation, or Run.
- **Agent Profile**: the Agent's internal self model: stable identity, effective capabilities, active Confirmed Facts, active Impressions, and context revision. Agent name and description remain canonical in `agents`.
- **Impression**: model-maintained, rich short-term observation derived from recent Conversation/Run/Memory evidence. It may be wrong, decays dynamically, remains internal, and is never an instruction.
- **Fact Candidate**: conservative proposal distilled from one or more Impressions. It cannot enter durable trusted Fact state without owner confirmation.
- **Confirmed Fact**: durable Fact explicitly confirmed by the owner (or a future deterministic verifier), with validity and revocation lifecycle.
- **Curator**: isolated no-Tool model call triggered by a durable job after a successful Run. It may maintain Impressions and Fact Candidates but cannot write Confirmed Facts.
- **Profile Version / Context Revision**: `version` protects optimistic concurrency for Identity, Confirmed Facts, and Disclosure Policy; `contextRevision` protects Impression and Fact Candidate changes. Candidate confirmation advances both.
- **AgentFacts**: signed external trust/discovery manifest generated by the Disclosure Engine from allowed Profile subjects. It is not the Agent's private self model.
- **AgentFacts Publication**: immutable, TTL-bound, JWS-signed, revocable AgentFacts version under one verified hostname.
- **Agent Index**: independent discovery process that currently registers and resolves AgentAddr navigation records and will later map lossy routing representations to candidates. Its results never replace Agent Server facts.
- **AgentCard**: A2A communication manifest. AegisLink currently provides an owner-only Draft and readiness blocker because no A2A endpoint exists.
- **Conversation**: durable thread bound to one Agent.
- **Run**: one execution attempt within a Conversation, including an immutable execution-policy snapshot.
- **Run Event**: ordered PostgreSQL event used for streaming, inspection, and replay.
- **Memory**: explicit, durable semantic or episodic Agent-scoped long-term context and evidence source. Automatic long-term extraction and vector retrieval are not implemented.
- **Skill Package / Version**: Principal-owned package with immutable content versions; each Agent selects and enables one Version through a binding.
- **MCP Library**: Principal-owned MCP Servers and discovered Tools.
- **MCP Binding**: per-Agent Server/Tool enablement; it is the authorization source for Runtime availability.
- **Mention Catalog**: server projection used by `@` and the Composer capability menu. It is not a public Agent directory.
- **Disclosure Policy**: authoritative visibility, channel, indexing, and audience rules for identity, capabilities, Confirmed Facts, and endpoints. Impressions are never disclosure subjects.
