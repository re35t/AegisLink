# AegisLink 愿景

AegisLink 是 Personal Agent OS：每个用户控制一个长期存在的 Agent，拥有持久化 Conversation、可审查 Memory、可安装 Skill、显式 Tool 权限和可编辑 Profile。

Personal Agent OS 继续坚持 local-first 与单 Owner。AgentFacts 已在明确的 Discovery/Trust 场景中使用独立签名、过期和撤销机制，但这不是通用 Agent 身份协议。现在已有明确的小规模网络发现工作流，因此引入独立且受限、具有基础 AgentAddr Registry 的 Index；它必须保持为导航基础设施，不能把 Organization、Multi-Agent Orchestration 或共享所有权带入 Personal Agent Server。
