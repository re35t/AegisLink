# AegisLink 愿景

AegisLink 是 Personal Agent OS：每个用户控制一个长期存在的 Agent，拥有持久化 Conversation、可审查 Memory、可安装 Skill、显式 Tool 权限和可编辑 Profile。

当前产品坚持 local-first 与单 Owner。AgentFacts 已在明确的 Discovery/Trust 场景中使用独立签名、过期和撤销机制，但这不是通用 Agent 身份协议。安全的跨 Agent 协作可以作为未来方向；在出现真实工作流前，不提前引入中央 Directory、Organization、跨 Agent Routing 或分布式系统抽象。
