# AegisLink vision

AegisLink is a Personal Agent OS: each user controls a persistent Agent with durable Conversations, reviewable Memory, installable Skills, explicit Tool permissions, and an editable Profile.

The Personal Agent OS remains local-first and single-owner. AgentFacts uses signing, expiry, and revocation for one explicit Discovery/Trust boundary; this is not a general Agent identity protocol. A concrete small-network discovery workflow now justifies a separate, bounded Index with a basic AgentAddr Registry. It must remain navigation infrastructure rather than introducing organizations, multi-Agent orchestration, or shared ownership into the Personal Agent Server.
